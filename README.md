# Quản Lý Thư Viện

## 1. Giới thiệu

Đây là chương trình quản lý sách thư viện viết bằng ngôn ngữ C, chạy trên console. Người dùng chọn chức năng bằng menu đánh số.

Chương trình giải quyết việc quản lý sách bằng tay: thay vì ghi chép riêng lẻ, mọi sách và việc mượn trả đều được quản lý trong một chương trình.

Các tính năng chính:

- Thêm, cập nhật, xóa sách
- Hiển thị danh sách và tìm kiếm sách
- Mượn sách, nhận trả sách
- Lọc và sắp xếp sách
- Thống kê

## 2. Thành viên và phân công

| STT | Họ tên | Nhiệm vụ |
|:---:|--------|----------|
| 1 | Hiền | - Viết khung chương trình với các tính năng cơ bản<br>- Kiểm tra, tối ưu code<br>- Sửa lỗi |
| 2 | Thành | - Thêm tính năng mượn, trả sách<br>- Lên kế hoạch dự án<br>- Thuyết trình |
| 3 | Quỳnh Anh | - Thêm tính năng lọc sách<br>- Sửa lại phần hiển thị<br>- Thuyết trình |

## 3. Cách biên dịch và chạy

**Môi trường:**

- Ngôn ngữ: C
- Trình biên dịch: GCC
- Hệ điều hành: Windows

**Biên dịch:**

```bash
gcc QuanLySach.c -o QuanLySach
```

**Chạy:**

```bash
.\QuanLySach.exe
```

Chạy xong sẽ hiện menu, nhập số của chức năng cần dùng rồi nhấn Enter. Nhập `0` để thoát.
